# Распознавание госномеров на видео

Решение полуфинала конкурса Volga IT 2025. Программа на Go читает запись с камеры,
находит номерные знаки автомобилей и пишет в CSV, когда какой номер появился в кадре.
Стек: Go, OpenCV (gocv), Tesseract (gosseract).

## Как это работает

1. **Выборка кадров.** Обрабатывается кадр раз в 200 мс (каждый пятый при 25 FPS): этого
   достаточно, чтобы не пропустить машину, и это держит задержку ниже 100 мс на кадр на
   обычном CPU.
2. **Детекция номера.** Основной путь — классическое компьютерное зрение: перевод в оттенки
   серого, размытие, границы Canny, морфологическое закрытие, поиск контуров и фильтр по площади
   и пропорциям 2:1–6:1. Если рядом лежит ONNX-модель, используется нейросетевой детектор
   (см. «Ограничения»).
3. **Распознавание.** Вырезанный номер увеличивается, бинаризуется адаптивным порогом и
   распознаётся Tesseract со списком символов, допустимых в российских номерах. Кириллица
   приводится к латинице (`А→A`, `В→B`, …).
4. **Дедупликация.** Один и тот же номер не записывается чаще раза в 3 секунды.

Результат — CSV `time;plate_num`. Подробная пояснительная записка с обоснованием выбора
алгоритмов — в [EXPLANATION.md](EXPLANATION.md), установка зависимостей — в [INSTALL.md](INSTALL.md).

## Запуск

Нужны Go, OpenCV и Tesseract (см. INSTALL.md).

```bash
go run . -video path/to/video.mp4 -output results.csv
```

Видео и эталонная разметка организаторов в репозиторий не входят — это их материалы.
Проверка качества на своём видео с разметкой в формате
`time_start;time_detect;time_end;plate_num;is_vehicle`:

```bash
python validate_results.py results.csv path/to/ground_truth.csv
```

## Ограничения и что дальше

- Нейросетевая ветка разбирает выход в формате YOLOv5 (objectness в пятой колонке,
  нормированные координаты). YOLOv8 экспортирует тензор `1×(4+N)×8400` без objectness и с
  координатами в пикселях входа, поэтому постобработку нужно переписать под этот формат.
- `train_model.py` с вариантом 2 скачивает общую YOLOv8n, обученную на COCO: она не обучена на
  номерах. Для детекции номеров нужен вариант 1 — обучение на датасете номеров.
- Метрики в EXPLANATION.md — оценки, а не измерения; следующий шаг — автоматический прогон
  `validate_results.py` на размеченном фрагменте и тесты для нормализации и дедупликации.
